# Local Console Hub v0.3.0 — 已添加的应用可以编辑

更新：2026-11-10。Windows x64。

- **编辑已添加的应用**：停止状态的应用在会话标题栏出现「编辑」，打开与「添加应用」相同的表单，预填名称、目录、命令、端口、网页地址、用途、关闭影响、日志策略、显示方式与生命周期。保存只改写配置文件里的那一条：其他条目、注释和顺序保持原样，会话 id 不变；运行中的应用需先停止。
- **停止不再冻结窗口**：停止、启动、重启、端口刷新、日志与确认结束等命令移出主线程。停止一个不响应关闭的进程树时，窗口和托盘保持可响应，能实时显示「正在停止」。
- **停止失败后可以恢复**：进入 `Error` 但仍持有进程树的会话，可以再次停止或强制结束；「重启」会先结束旧 run 再启动新 run，不再把旧句柄的清理塞进启动锁里。
- **大进程树也能停干净**：进程树超过 512 个进程时，查询缓冲按需扩容（上限 65,536），不再让确认结束直接失败。
- **终端启动参数修复**：带空格且以反斜杠结尾的路径（如 `D:\My Dir\`）不再吞掉闭合引号，内嵌终端收到的 argv 与配置一致。
- **ConPTY 环境块**按变量名排序，`term`/`Term`/`TERM` 统一替换为 `TERM=xterm-256color`，不再出现重复变量。
- **端口页与确认结束**按活动进程判断归属：`Starting`/`Stopping`/`Error` 中仍存活的 run 也在保护名单里，已结束会话的旧 handle 不会因 pid 复用误认。
- 启动失败会清空开始时间；配置文件写盘在 rename 前 `fsync`，掉电不再可能留下空或截断的 `config.yaml`。

## 安装

从发布页下载 `Local Console Hub_0.3.0_x64-setup.exe`（当前用户安装）或 MSI（所有用户安装，需要管理员权限），选择一个。

已有版本先通过托盘菜单 **退出**，再安装；只关闭主窗口会继续在后台运行。建议继续使用原来的安装包类型和目录，并先备份配置与日志。

## 验证与已知限制

前端 361 项测试通过；Rust 侧在 Ubuntu + cargo-xwin 交叉检查（`fmt`、`clippy -D warnings`、`cargo check --all-targets`）通过，并在 Wine 下逐项运行了配置编辑、保存、停止/重启、Job 与状态机相关用例。安装包未签名，Windows SmartScreen 首次运行会提示「未知发布者」；缺少 WebView2 时安装器会联网获取运行时。本轮没有执行新安装包的安装、覆盖升级或卸载验收；真实窗口中的编辑与停止流畅度需要在 Windows 桌面上手工验收。
