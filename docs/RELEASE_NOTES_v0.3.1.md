# Local Console Hub v0.3.1 — 第三轮排查修复

更新：2026-11-14。Windows x64。本版不含新功能，是对 v0.3.0 的整体缺陷排查修复。

- **32 位程序的显示建议修复**：「添加应用」读取可执行文件的子系统时用错了偏移——32 位程序读到的是校验和字段，推荐结果基于偶然值。现在 32 位与 64 位程序都读真正的 `Subsystem` 字段，控制台程序如常推荐独立窗口。
- **托盘菜单不再停留在旧状态**：多个会话同时报状态时，菜单重建的并发交错可能让托盘停留在过期状态且后续事件无法纠正。现在重建过程串行化，最后进来的读数总是最终显示的。
- **Hub 外启动的 .bat 应用能被识别**：用户以 `run.bat`、`cmd /c run.bat` 这类常见写法启动已配置的批处理应用时，Hub 不再误判「没有在运行」而另启一份；这类无法确认归属的实例改为进入选择对话框，由用户决定。
- **健康读数不再残留**：一次探测跨过停止动作时，旧进程的读数不再写回已结束的会话。
- **启动失败后的 Error 快照**不再残留上一轮运行的退出码。
- `https://主机:0/` 形式的健康 URL 不再探测默认端口（此前 443 的应答会冒充这条 URL 的结果）。
- **配置校验拒绝 Windows 设备名**：手写配置把会话 id 设为 `nul`、`con`、`com1` 等会在启动时得到明确的逐条错误，而不是日志永远写不进去。
- **应用日志保护修复**：`logging.path` 指向 Hub 日志树内的应用日志，此前因配置里大小写与磁盘不一致而可能被「清理旧日志」误删；现在按 Windows 的路径语义匹配。
- 两条错误提示中的连续空格。

## 安装

从发布页下载 `Local.Console.Hub_0.3.1_x64-setup.exe`（当前用户安装）或
`Local.Console.Hub_0.3.1_x64_en-US.msi`（所有用户安装，需要管理员权限），选择一个。

已有版本先通过托盘菜单 **退出**，再安装；只关闭主窗口会继续在后台运行。建议继续使用原来的安装包类型和目录，并先备份配置与日志。

[安装与使用教程](https://github.com/Civinar-Riley/Local-Console-Hub/blob/v0.3.1/docs/USER_GUIDE.md) ·

## 验证与已知限制

前端 361 项测试通过；Rust 侧 `fmt`、`clippy -D warnings`、`cargo check --all-targets`（x86_64-pc-windows-msvc）通过，windows-gnu 目标在 Wine 下逐项运行了本轮改动相关的用例（52/55，3 个真实进程取证用例依赖真实 Windows 进程表，与基线一致为环境限制）。安装包未签名，Windows SmartScreen 首次运行会提示「未知发布者」；缺少 WebView2 时安装器会联网获取运行时。本版未执行新安装包的安装、覆盖升级或卸载验收；「Hub 外启动 .bat 被识别为选择对话框」的完整流程需要在 Windows 桌面上手工验收。
